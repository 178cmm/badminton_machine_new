# 🎯 自定義發球控制頁面使用指南

## 📋 功能概述

自定義發球控制頁面提供了一個直觀的界面，讓使用者能夠：

1. **直接輸入4個發球參數**：速度、水平角度、垂直角度、高度
2. **建構自定義球序**：排列多顆不同參數的球
3. **依序發球**：按照設定的順序和間隔時間發球
4. **保存和載入球序**：將常用的球序保存為檔案

## 🎮 界面布局

### 左側：參數控制區
- **發球參數設定**：4個參數的直接輸入控制
  - 速度 (1-10)
  - 水平角度 (0-60°)
  - 垂直角度 (0-60°)
  - 高度 (0-10)
- **參數預覽**：即時顯示當前參數值
- **測試發球**：使用當前參數發送一顆球
- **添加到球序**：將當前參數添加到右側的球序中

### 右側：球序建構器
- **球序列表**：顯示已添加的球及其參數
- **球序控制**：上移、下移、刪除、清空球序
- **球序操作**：保存球序到檔案、從檔案載入球序
- **播放控制**：設定發球間隔時間、開始播放球序

### 底部：狀態顯示
- **即時日誌**：顯示操作狀態和發球結果

## 🚀 使用步驟

### 1. 設定發球參數
1. 在左側參數控制區調整4個參數值
2. 觀察參數預覽區確認設定正確
3. 點擊「🎯 測試發球」驗證參數效果

### 2. 建構球序
1. 設定好第一顆球的參數後，點擊「➕ 添加到球序」
2. 輸入球的名稱（例如：「正手高遠球」）
3. 重複步驟1-2，添加更多球到序列中
4. 使用上移/下移按鈕調整球的順序
5. 使用刪除按鈕移除不需要的球

### 3. 保存球序
1. 點擊「💾 保存球序」
2. 選擇保存位置和檔案名稱
3. 球序將保存為JSON格式檔案

### 4. 載入球序
1. 點擊「📁 載入球序」
2. 選擇之前保存的球序檔案
3. 球序將載入到球序列表中

### 5. 播放球序
1. 設定發球間隔時間（1.0-10.0秒）
2. 點擊「▶️ 開始發球」
3. 系統將按照球序依序發球
4. 觀察狀態日誌了解發球進度

## ⚙️ 技術細節

### 發球參數說明
- **速度 (1-10)**：控制球的飛行速度，數值越大速度越快
- **水平角度 (0-60°)**：控制球的左右方向，0°為正前方
- **垂直角度 (0-60°)**：控制球的上下方向，0°為水平
- **高度 (0-10)**：控制球的發射高度 ⚠️ **注意：在現有配置中，所有區域的高度參數都設為0，此參數可能未啟用或通過其他方式實現**

### 間隔參數說明
- **發球間隔 (1.0-10.0秒)**：控制連續發球之間的時間間隔
- 這是軟體層面的控制參數，不是發球機硬體參數
- 用於控制球序播放時每顆球之間的等待時間

### 球序檔案格式
球序以JSON格式保存，包含以下資訊：
```json
[
  {
    "name": "球的名稱",
    "params": {
      "speed": 2,
      "horizontal_angle": 0,
      "vertical_angle": 50,
      "height": 0
    },
    "id": 0
  }
]
```

### 發球指令
系統使用 `create_shot_command()` 函數創建發球指令，包含：
- 速度、水平角度、垂直角度、高度參數
- CRC16校驗碼
- 標準的發球機通訊協定格式

## 🔧 整合說明

### 與現有系統的整合
- 使用現有的 `commands.py` 中的 `create_shot_command()` 函數
- 支援通過藍牙線程發送自定義參數的發球指令
- 支援模擬模式，可在沒有實體發球機時測試功能
- 與主GUI系統完全整合，作為新的標籤頁

### 發球機連接
- 自動檢測可用的發球機連接方式
- 優先使用藍牙線程連接
- 支援設備服務連接
- 支援模擬模式

## 🎯 使用場景

### 1. 教練自定義訓練
- 根據學員能力調整發球參數
- 創建針對性的訓練球序
- 保存常用訓練方案

### 2. 技術測試
- 測試不同參數組合的效果
- 驗證發球機的參數範圍
- 調試發球機設定

### 3. 進階訓練
- 創建複雜的球序組合
- 模擬真實比賽場景
- 進行多球路訓練

## ⚠️ 注意事項

1. **發球機連接**：確保發球機已正確連接並處於就緒狀態
2. **參數範圍**：請在建議的參數範圍內設定，避免損壞發球機
3. **發球間隔**：建議設定適當的間隔時間，避免發球機過載
4. **球序長度**：建議球序長度不超過50顆球，以確保穩定性
5. **檔案備份**：定期備份重要的球序檔案

## 🆘 故障排除

### 發球指令發送失敗
- 檢查發球機連接狀態
- 確認藍牙連接正常
- 嘗試重新連接發球機

### 球序播放中斷
- 檢查發球機電源
- 確認球序檔案完整性
- 重新載入球序

### 參數設定無效
- 確認參數在有效範圍內
- 檢查發球機是否支援該參數組合
- 嘗試重置參數到預設值

## 📞 技術支援

如有技術問題，請檢查：
1. 系統日誌中的錯誤訊息
2. 發球機連接狀態
3. 參數設定是否正確
4. 球序檔案格式是否正確
