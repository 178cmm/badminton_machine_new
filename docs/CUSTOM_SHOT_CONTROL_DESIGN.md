# 🎯 自定義發球控制頁面設計說明

## 📐 整體架構

```
自定義發球控制頁面
├── 標題區域
│   └── "🎯 自定義發球控制"
├── 主內容區域 (水平分割器)
│   ├── 左側：參數控制區 (40%)
│   │   ├── 發球參數設定
│   │   │   ├── 速度控制 (1-10)
│   │   │   ├── 水平角度控制 (0-60°)
│   │   │   ├── 垂直角度控制 (0-60°)
│   │   │   └── 高度控制 (0-10)
│   │   ├── 參數預覽
│   │   ├── 測試發球按鈕
│   │   └── 添加到球序按鈕
│   └── 右側：球序建構器 (60%)
│       ├── 球序列表
│       ├── 球序控制按鈕
│       │   ├── 上移/下移
│       │   ├── 刪除/清空
│       ├── 球序操作按鈕
│       │   ├── 保存球序
│       │   └── 載入球序
│       └── 播放控制
│           ├── 發球間隔設定
│           └── 開始發球按鈕
└── 底部：狀態顯示
    └── 即時日誌區域
```

## 🎨 界面設計原則

### 1. 直觀性
- **參數控制**：使用 SpinBox 提供精確的數值輸入
- **即時預覽**：參數變更時立即顯示預覽
- **視覺回饋**：不同顏色區分不同參數類型

### 2. 易用性
- **拖拽排序**：球序列表支援上移/下移操作
- **一鍵操作**：測試發球、添加到球序等一鍵完成
- **檔案管理**：支援球序的保存和載入

### 3. 穩定性
- **參數驗證**：確保參數在有效範圍內
- **錯誤處理**：完善的錯誤提示和處理機制
- **狀態監控**：即時顯示操作狀態和結果

## 🔧 技術實現

### 1. 參數控制組件 (ParameterControlWidget)
```python
class ParameterControlWidget(QWidget):
    - 4個 SpinBox 控制元件
    - 參數變更信號 (sig_parameters_changed)
    - 測試發球信號 (sig_test_shot)
    - 參數預覽功能
```

### 2. 球序建構器 (ShotSequenceBuilder)
```python
class ShotSequenceBuilder(QWidget):
    - QListWidget 顯示球序
    - 球序操作按鈕
    - 檔案保存/載入功能
    - 播放控制功能
```

### 3. 主控制界面 (CustomShotControlWidget)
```python
class CustomShotControlWidget(QWidget):
    - 水平分割器布局
    - 信號連接和事件處理
    - 發球指令發送邏輯
    - 球序播放邏輯
```

## 📊 資料流程

### 1. 參數設定流程
```
使用者調整參數 → 參數變更信號 → 更新預覽 → 發送測試發球
```

### 2. 球序建構流程
```
設定參數 → 添加到球序 → 更新球序列表 → 調整順序 → 保存球序
```

### 3. 發球執行流程
```
載入球序 → 設定間隔 → 開始播放 → 依序發球 → 完成/停止
```

## 🎯 核心功能

### 1. 自定義參數發球
- 直接輸入4個發球參數
- 即時參數預覽
- 一鍵測試發球
- 與現有發球機系統整合

### 2. 球序管理
- 視覺化球序建構
- 拖拽排序功能
- 球序保存/載入
- 球序編輯功能

### 3. 依序發球
- 可設定發球間隔
- 自動依序播放
- 即時狀態顯示
- 支援暫停/停止

## 🔗 系統整合

### 1. 與現有系統的整合點
- **commands.py**：使用 `create_shot_command()` 函數
- **bluetooth.py**：通過藍牙線程發送指令
- **main_gui.py**：作為新的標籤頁整合
- **device_service.py**：支援設備服務連接

### 2. 發球指令發送機制
```python
def _send_custom_shot(self, params):
    1. 創建發球指令 (create_shot_command)
    2. 嘗試藍牙線程發送
    3. 嘗試設備服務發送
    4. 支援模擬模式
    5. 錯誤處理和日誌記錄
```

### 3. 球序播放機制
```python
def _play_sequence(self, sequence):
    1. 初始化播放狀態
    2. 依序發送每顆球
    3. 使用 QTimer 控制間隔
    4. 更新播放進度
    5. 處理播放完成/停止
```
